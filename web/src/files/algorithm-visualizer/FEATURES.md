# Algorithm Visualizer

> An interactive online platform that visualizes algorithms from code.

## Features

- **Visualize algorithms from code** — Write code and watch it come alive: every array write, chart update, graph visit and log line is animated step by step.

- **Four languages** — JavaScript runs right in your browser; C++, Java and Python run on the server. Each language ships a tracer library with the same API, so examples translate line by line.

- **Interactive player** — Play, pause, step forward and backward, scrub the progress bar and change the speed. The editor highlights the exact line being executed.

- **Tracers for every data shape** — `Array1DTracer`, `Array2DTracer`, `ChartTracer`, `GraphTracer` and `LogTracer`, plus randomizers that generate test data for you.

- **A built-in library of classics** — Backtracking, Branch and Bound, Divide and Conquer, Dynamic Programming, Greedy, Brute Force and more, each with readable reference code in every supported language.

- **Scratch Paper** — A blank canvas for your own code. Pick a language, write an algorithm, and visualize it without leaving the page.

- **Save and share with GitHub** — Sign in with GitHub to save your visualizations as Gists and open them again from any machine.

## Getting Started

Pick an algorithm from the menu on the left, choose a language, and press **Run**. Then try the Scratch Paper and visualize something of your own.
