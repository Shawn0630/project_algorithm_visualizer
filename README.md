# Algorithm Visualizer

## Introduction
Welcome to Algorithm Visualizer, an interactive online platform designed to bring algorithms to life through visualization. Whether you're a student, teacher, or professional, our platform provides an engaging way to explore and understand various algorithms.

## Project structure

- `web/`: React web application.
- `server/`: Backend API and code execution services.
- `algorithms/`: Algorithm visualization examples.
- `tracers.java/`: Java visualization library.
- `tracers.py/`: Python visualization library.
- `extractor.java/`: Java command extraction tools.
- `leetcode/`: Practice solutions.

See the README files in each component for setup and usage details.
Local environment files and generated dependencies are excluded from Git.

This project includes components from [Algorithm Visualizer](https://github.com/algorithm-visualizer). See the component directories for their licenses and attribution.
